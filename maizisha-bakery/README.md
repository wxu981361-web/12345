# 麥日子｜手作烘焙

溫暖手作風格的麵包店形象網站，使用原生 HTML、CSS 與 JavaScript，無需安裝套件。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。

## 部署到 Vercel

1. 將此資料夾推送到 GitHub repository。
2. 在 Vercel 選擇 **Add New → Project**，匯入該 repository。
3. Framework Preset 選 **Other**，Build Command 與 Output Directory 留空，然後部署。

首頁圖片由 Unsplash 載入，需連線才能顯示。
